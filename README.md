# Resume Page Using Bootstrap

A responsive personal resume and portfolio website built with **HTML5** and **Bootstrap 5**. The page presents my background, education, technical skills, projects, and contact information in a clean, card-based layout.

## Overview

This project is a personal portfolio page designed to make my academic background and technical experience easy to explore. It uses Bootstrap's grid system, utility classes, badges, and cards to create a layout that adapts to different screen sizes.

## Features

- **Profile and summary** — introduction and areas of interest.
- **Education** — university degree and diploma thesis information.
- **Technical skills** — programming languages, databases, frameworks, and libraries.
- **Projects** — selected work with technology tags and links to repositories or publications.
- **Responsive layout** — Bootstrap grid and responsive utility classes for desktop and mobile screens.
- **External links** — direct links to relevant project repositories and research.

## Built With

- HTML5
- CSS
- [Bootstrap 5.3](https://getbootstrap.com/)
- [Bootstrap Icons](https://icons.getbootstrap.com/) for interface icons

## Project Structure

```text
Resume-Page-Using-Bootstrap/
└── Resume Page Using Bootstrap/
    ├── index.html
    └── personal.jfif
```

The main page is `index.html`. The `personal.jfif` file is used for the profile image.

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Tsomaros/Resume-Page-Using-Bootstrap.git
   ```

2. Open the project folder, then open `Resume Page Using Bootstrap/index.html` in your browser.

No build step or package installation is required. Bootstrap is loaded through a CDN, so an internet connection is needed for its styles to load.

## Customization

- Update the profile, education, skills, projects, and contact details in `index.html`.
- Replace `personal.jfif` with your own image and update its `src` attribute if the filename changes.
- Adjust the Bootstrap classes and CSS to customize the colors, spacing, and layout.
- Replace the example project links with your own repositories and publications.

## Purpose

This project was created to practise responsive web design and present my experience in **Computer Engineering, Machine Learning, Computer Vision, and Full-Stack Development** in a portfolio-friendly format.
